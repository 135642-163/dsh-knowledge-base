## 新发现：TB/T 2799-1997 是 GBK-as-Latin1 乱码

- 症状：派生正文 94% 是 Latin-1 扩展符号（`Ð ª Ë ñ ² Í` 等），可读中文几乎为零；
- 证据：`kb_view page=1` 原页清晰（中华人民共和国铁道行业标准 TB/T 2799—1997）；
- 全库扫描：884 篇里**只有这一篇**命中该形态（按「1–2 字符的 Latin-1 token 占比」判定，
  英文/法文资料里的 `° ± µ ² ³` 不会被误判）；
- 修复建议：`kb_reparse doc="TB/T 2799-1997" forceOcr=true`（5 页 OCR），
  **这是阶段 2 唯一的候选写入**，需要先 `kb_snapshot` + dry-run + 你确认。
  另建议 0.37 让解析器识别「GBK 文本层被按 Latin-1 解码」并自动回退，避免再次出现。
