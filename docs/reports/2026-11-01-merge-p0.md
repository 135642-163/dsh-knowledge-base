## 已实现语义

- 同 id 同内容 → skip；
- 同 id 异内容 → rename 保留两份；
- 同标准号+年份+阶段 → 默认 skip；`duplicatePolicy=keep` 可改名保留；
- 同号不同年/阶段 → 保留并 warning；
- 部分合并（有 skipped）→ 源库不标 `mergedInto`，继续可见；
- 全空源库 → `mergedInto/mergedAt/mergePurgeAfter=+7d`；源文件先保留；
- 下次插件启动时若已到期 → 删 `sources/markdown/history/import-tmp`，保留 `kb.json/schema/index/log` 墓碑；
- 未到期或用户不上线 → 不清理；
- 无 `trashRetentionDays` 依赖（它跳过 merged 库）。

## 两种“合并”的边界

- **A. 本地库合并**：本 P0；物理移动本机 A/B 到 C，源库归档。
- **B. 外部 kbpack 导入合并**：已有 `kb_import_package mode=merge`；包是文件，导入目标库，不做源库归档。P0 未改它；P1 可复用 duplicatePolicy/preview 语义。
