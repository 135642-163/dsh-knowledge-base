## 0.38 新增功能验收（重点）

1. 打开工作台，侧栏出现「**数据目录**」；
2. 弹窗显示「当前生效：`E:\个人工作文件\knowledge`（来自插件配置）」；
3. `GET /kb/api/settings` 返回 `kbRoot` / `kbRootSource` / `configKbRoot` / `savedKbRoot` / `restartRequired`；
4. 可选完整验证（会临时改用新目录，可随时恢复默认）：
   - 新建空目录（如 `E:\个人工作文件\knowledge-test`），在弹窗保存；
   - 页面提示「重启 DSH 后生效」，`restartRequired=true`，旧目录资料不被移动；
   - 重启后 `kb_list` 显示新目录（空库），`/kb/api/status` 的 `kbRootSource=setting`；
   - 在弹窗点「恢复默认」→ 再重启，回到 `E:\个人工作文件\knowledge`。
5. 回归：`kb_list` / `kb_query`（首次索引回退一次属预期）/ `kb_read` / `kb_lint` 正常；
   0.37 的无页码 `pageStart` 问题不应复现。
