# 0.35.1 Windows 修复（2026-11-01）

基线 0.35.0；测试 **1313**（1309 通过、4 跳过，0 失败）。

## 修复

- `kb_export` 的 `out` 父目录不存在时自动 `mkdir -p`；创建失败返回 `EXPORT_OUT_DIR`，
  避免裸 ENOENT 冒到宿主层；
- Windows `rename` 对 `EPERM`/`EBUSY`/`EACCES` 做 3 次短退避重试（25/50ms），覆盖
  import-tmp→markdown、source、历史恢复、清单原子写、库目录 rename；
- 导入跳过文案按 `reason` 显示：重复/库内完整版本/双方残缺/正在导入，不再一律说“正在导入中”；
- 知识库卡片可信度条与库名圆点提高饱和度/亮度；
- 同步更新测试与 `ui-overview` 颜色断言。
