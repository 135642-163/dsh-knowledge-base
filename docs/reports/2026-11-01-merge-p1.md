# 合并知识库 P1：API + 工作台向导（2026-11-01）

## API

- `GET /kb/api/status` 的 `features.merge` 改为 `true`；
- `POST /kb/api/merge/preview`
  - body `{ sources, target: {name, create?, description?, tags?}, duplicatePolicy }`
  - 返回 `{ plan }`，不写任何文件；
- `POST /kb/api/merge`
  - 必须 `confirm: true`；
  - 先 plan；无移动项时返回 `{jobId:null, hint}`，有则 `{jobId, plan}`；
  - 后台 job kind `kb-merge`，调用 `executeMerge`，结果含 move/rename/skip/notesAffected/journal；
- 错误映射：`MergeError` → 400/404/409/413。

## 工作台

- 总览页新增「合并库」按钮；
- 弹窗：
  - 勾选 2+ 个源库（排除已合并库）；
  - 目标：新建库 / 已有库；
  - 重复策略：跳过同号同版本（默认）/ 保留两份；
  - 「预览」显示 move/rename/skip/冲突/多版本/受影响笔记；
  - 「确认合并」启动后台 job 并轮询，完成后刷新列表。
- 预览不会创建目标库/写文件；确认后才执行。

## 测试
