# 0.35.0 合并知识库 + 导入质量闸门（2026-11-01）

基线 0.34.0；测试 **1306**（1302 通过、4 跳过，0 失败）。

## 导入质量闸门

- `kb_import` 导入前检测同库「同标准号不同年份/阶段/缺年份」：
  - 默认先暂停冲突文件，返回 `versionConflicts` / `versionConfirmed:false`；
  - 加 `allowSameNumber: true` 确认后仍可入库；
  - 跨库同号多版本只提示不阻断；
  - 可用 `title` 修正年份/阶段后再导入。
- 新增 `versionConflict` 到 `lib/dedup.js`；工具与 API 兼容旧调用。

## 本地知识库合并（A 方案）

- 后端 `lib/merge.js`：`planMerge` / `executeMerge` / `undoMerge` / `sweepMergedSources`；
- API：`/kb/api/merge/preview`、`/kb/api/merge`、`/kb/api/merge/undo`；`features.merge=true`；
- 工作台：总览「合并库」向导 + 预览 + 后台任务 + 完成后「撤销本次合并」；
- 重复策略：同号同版本默认跳过，`keep` 保留两份；同号不同年/阶段保留并警告；
- 源库全空才 `mergedInto`，`mergePurgeAfter=+7d`；插件启动时懒清理，离线不清理；
- 部分合并源库保持可见；合并 journal/快照/回滚齐全；undo 支持全量与部分合并；
- 改名时自动改写笔记 `sources`/`linksOut`，undo 反向恢复；
- 外部 kbpack `mode=merge` 也支持 `duplicatePolicy=skip|keep` 与 `versionConflicts`，语义对齐本地合并。
